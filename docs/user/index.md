# Benutzerhandbuch

Benutzer arbeiten im Browser, mit dem Desktop Client oder über mobile Apps. Die Hauptbereiche sind Dateien, Freigaben, Papierkorb, Versionen, Favoriten und externe Speicher.

## Anmeldung

![Login](../assets/screenshots/owncloud-online-login.png)

1. URL der Instanz öffnen.
2. Benutzername oder E-Mail eintragen.
3. Passwort eintragen.
4. Bei aktivierter Zwei-Faktor-Authentifizierung den TOTP-Code eingeben.

## Dateien

![Dateien](../assets/screenshots/owncloud-online-files.png)

Die Dateienansicht zeigt persönliche Dateien, Favoriten, Freigaben, Links, Tags und gelöschte Dateien.

## Teilen

![Freigabe eines Dokuments](../assets/screenshots/owncloud-online-sharing.png)

Ein Klick auf das Freigabesymbol in der Dateiliste öffnet die Seitenleiste.
Dort gibt es zwei Wege:

* **Nutzer und Gruppen** — Name eintippen, Rechte je Freigabe setzen (ansehen,
  ändern, weiterteilen, löschen).
* **Öffentliche Links** — für Empfänger ohne Konto. Ein Link lässt sich mit
  Passwort und Ablaufdatum versehen und auf reines Lesen oder auf Hochladen
  beschränken.

Bestehende Freigaben stehen in derselben Ansicht und lassen sich dort ändern
oder zurücknehmen.

## Sicherheit

Benutzer sollten:

- ein starkes Passwort verwenden
- 2FA einrichten, wenn die App aktiv ist
- alte Browser-Sitzungen entfernen
- öffentliche Links regelmäßig prüfen
