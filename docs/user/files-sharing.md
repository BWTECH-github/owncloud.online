# Dateien und Freigaben

## Datei hochladen

1. Dateien-App öffnen.
2. `+` klicken.
3. Datei auswählen.
4. Upload abwarten.

## Ordner anlegen

1. Dateien-App öffnen.
2. `+` klicken.
3. Ordnername eintragen.
4. Ordner erstellen.

## Freigabe erstellen

1. Datei oder Ordner auswählen.
2. Freigabe-Symbol öffnen.
3. Benutzer, Gruppe oder Link wählen.
4. Berechtigungen setzen.

## Öffentlicher Link

Für öffentliche Links sollten Ablaufdatum und Passwort verwendet werden, wenn die Instanz externe Nutzer zulässt.

## Versionen und Papierkorb

Gelöschte Dateien liegen im Papierkorb. Geänderte Dateien können über Versionen wiederhergestellt werden, wenn `files_versions` aktiv ist.
